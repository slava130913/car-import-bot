# Чек-лист запуска

## 1. Бот (10 минут)

1. В Telegram открыть @BotFather → `/newbot` → имя и username (например `china_auto_calc_bot`).
2. Скопировать токен в `.env` → `BOT_TOKEN=`.
3. Узнать свой id у @userinfobot → `.env` → `ADMIN_IDS=`.
4. Решить, как брать деньги за отчёт по VIN:
   - `VIN_PRICE_STARS=500` — оплата звёздами внутри Telegram, деньги выводятся через Fragment (нужен аккаунт TON). Самый быстрый старт.
   - `VIN_PRICE_STARS=0` и `PAYMENT_INSTRUCTIONS=Переведите 1500 ₽ по СБП на номер … и пришлите чек` — оплата вне бота.
5. `python -m bot.main`, написать боту `/start`, прогнать все три сценария.
6. В @BotFather → `/setcommands`:
   ```
   start - Главное меню
   calc - Рассчитать стоимость под ключ
   vin - Проверить машину по VIN
   lead - Оставить заявку на подбор
   help - Как это работает
   ```

## 2. Сайт и Mini App

1. В `web/index.html` заменить `YOUR_BOT_USERNAME`.
2. Выложить папку `web/` на любой статический хостинг с HTTPS. Варианты: GitHub Pages (бесплатно), Vercel, Timeweb Static.
3. @BotFather → `/mybots` → бот → Bot Settings → Menu Button → вставить URL сайта. Кнопка «Калькулятор» появится в боте.

## 3. Как делать отчёт по VIN вручную (пока нет партнёра)

1. Заказ приходит админу с VIN и контактом.
2. Купить отчёт по VIN на Taobao (поиск «车辆历史报告 VIN» или «车况查询»), либо через агента в Китае. Цена обычно 30–80 ¥.
3. Прогнать текст отчёта через LLM с промптом: «Переведи отчёт об истории китайского автомобиля на русский, сохрани все даты, пробеги и суммы, термины 4S店 → дилерский центр, 出险 → страховой случай, 过户 → смена владельца».
4. Оформить в PDF (шаблон: VIN, модель, дата отчёта, таблица событий, вывод «рекомендуем / не рекомендуем»).
5. Отправить клиенту в бот, закрыть заказ командой `/done <id>`.

Ограничение на старте: не больше 5 заказов в день, иначе не успеть за 24 часа.

## 4. Куда отдавать заявки

До запуска обзвонить 5 агентов в Москве и 2 в Туле. Вопросы:
- Сколько готовы платить за подтверждённую заявку (модель, бюджет, контакт)?
- Готовы ли на процент со сделки вместо фиксированной платы?
- Сколько сделок в месяц закрывают?

Выбрать двух-трёх. Заявки передавать вручную из `/leads`, фиксировать в таблице, кому отдал.

## 5. Первый трафик

**Комментарии под роликами** (Околоофициалы, Тимофей Автоподбор Китай, и похожие). Шаблон, когда человек спрашивает «сколько выйдет»:

> По вашим вводным (1.5T, 147 л.с., 2024 год, ~95 тыс. ¥) примерно 2,1 млн до Москвы: пошлина ~540 тыс., утиль льготный 3 400, логистика и оформление ~350 тыс. Если мощность выше 160 л.с., утиль станет от 900 тыс. Считал в боте @…, там разбивка по статьям.

Правило: сначала полезный ответ с числами, ссылка на бота в конце. Не больше 5 комментариев в день с одного аккаунта.

**Чаты перегонщиков в Telegram.** Зайти с инструментом: «сделал калькулятор с актуальным утилем и вилками по логистике, покритикуйте цифры». Критика перегонщиков = бесплатная сверка ставок.

**Блогер.** Предложить одному автору с 20–100 тыс. подписчиков: промокод на бесплатный отчёт по VIN для его зрителей, взамен упоминание бота. Первые 20 отчётов идут в минус, зато приходит трафик.

**Пост в своём канале** (если есть):

> Сделал бесплатный калькулятор «сколько стоит пригнать машину из Китая». Учитывает утильсбор по новым правилам (порог 160 л.с.), единые ставки пошлины, логистику по четырём маршрутам, СБКТС и ЭПТС. Показывает вилку, а не одну цифру. Ставки с датой и ссылками на источники. @…

## 6. Что мерить через 30 дней

| Метрика | Где смотреть | Решение |
|---|---|---|
| Расчётов в неделю | `/stats` | меньше 50 → проблема в трафике, не в продукте |
| Оплаченных отчётов | `/stats` | больше 30 в месяц → искать партнёра в Китае и автоматизировать |
| Заявок и сделок | `/leads` + своя таблица | хотя бы 1 сделка → строить кабинет агента |

## 7. Юридический минимум

- Самозанятость или ИП для приёма денег, если оплата вне Stars.
- Текст «расчёт ориентировочный, не является консультацией» уже есть в боте и на сайте.
- Персональные данные (телефоны): хранить на сервере в России, не передавать агентам без согласия клиента. В форме заявки стоит добавить фразу «оставляя контакт, вы соглашаетесь на передачу агенту».
